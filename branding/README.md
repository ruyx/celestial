## 📤 Cómo Usar

### Para YouTube Studio:
1. **Banner**: Personalización → Branding → Imagen del banner → Cargar
2. **Logo**: Personalización → Branding → Imagen → Cargar
3. **Marca de agua**: Personalización → Branding → Marca de agua del video → Cargar (usa el logo)

### Dimensiones Recomendadas:
- **Banner**: 2560x1440px (área segura: 1546x423px centro)
- **Logo/Avatar**: 800x800px mínimo (98x98px mínimo)
- **Marca de agua**: 150x150px (PNG transparente)
